# Workflow examples

These are copyable `.sclpll` examples sourced from the SCLPL project: HTTP and pagination patterns, transforms, control flow, cache/retry, modes, text-plugin use, and a Python-script step.

Validate a local example without executing it:

```powershell
sclpl validate 01-http-to-json.sclpll
```

Network-facing examples use placeholder hosts. Supply your own safe configuration and outputs before running one.
